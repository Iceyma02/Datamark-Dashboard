Inspection Result Codes

Each row in the inspection file represents one component on one asset. The checker inspects it and records exactly one result:

DM
Datamark — Mark Found & Scanned
The Datamark security label was present and successfully scanned. The unique 6–7 digit asset ID number is recorded in the DM/Result column. This is the positive outcome — everything as expected.
N/A
Not Accessible
The component exists but the checker could not physically reach it — obscured by cargo, sealed compartment, etc. Not a fault, but that component was not verified during this inspection.
N/F
Not Found — Component Missing
The component is physically absent from the asset. This is an alert-level result — may indicate theft, loss, or non-compliance. Requires immediate follow-up.
D/G
Damaged — Mark Unreadable
Component present but its Datamark mark is damaged, defaced, or unreadable. The mark needs replacement and the asset cannot be positively identified from this component.
N/M
Not Marked
Component exists and is accessible but has no Datamark label at all. Was never enrolled in the system or mark was completely removed. Requires re-marking.
DM/Result
Result Column — ID Number or Outcome Code
When DM=1, this column holds the unique Datamark asset serial number scanned from the label. For other outcomes it contains the code (D/G, N/F, N/M). Blank = N/A.
